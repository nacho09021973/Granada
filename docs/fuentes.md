# Fuentes

Este fichero está vacío a propósito.

Se rellenará **únicamente** con fuentes verificadas: referencias que se hayan
consultado directamente y cuyos datos se hayan comprobado. No se añadirá aquí
ninguna referencia recordada de memoria, reconstruida a partir de un título
plausible, ni citada de segunda mano sin haber visto el original.

Cada entrada deberá indicar qué afirmación concreta del proyecto sostiene, y
si esa afirmación es de tipo (A) matemática o de tipo (B) empírica, según la
distinción del README.

Mientras no haya nada que cumpla ese criterio, el fichero se queda como está.
